SIMULATION 01 / 교과 모형

가열 조건과 기체 발생·고체 잔류량

탄산나트륨 1몰 반응 → CO₂ 1몰 발생이라는 화학양론에, 교육용 반응 진행률 모형을 추가합니다.

반응식 및 가정

Na₂CO₃ + SiO₂ → Na₂SiO₃ + CO₂
X(t) = 1 − exp(−k(T)·t)
Pᵢ = nᵢ RT / V
m잔류 = 100g − m수분 − mCO₂

초기 원료는 총 100g, SiO₂는 충분하다고 가정합니다. k(1000K)=0.100min⁻¹, 활성화 에너지 120kJ/mol은 문헌 측정값이 아닌 가정값입니다. 모든 수분이 기화되고 발생 기체가 포집 용기로 이동한다고 가정합니다.

위의 기본 시뮬레이션값은 주어진 시간의 부분 반응 결과이고, 여기의 값은 원료가 모두 반응했다는 이론적 비교 기준입니다.

그래프는 가정한 Arrhenius–1차 반응 모형을 계산한 것으로 실제 유리고화 공정의 측정 결과가 아닙니다.

탐구에서 검증할 질문

기체의 화학양론적 최대 몰수는 온도만 바꾼다고 증가하지 않으며, 이상 기체 방정식은 가열 반응의 전환율을 직접 결정하지 않습니다. 실제 용융로는 이 가상 밀폐 포집 용기와 다르게 기체가 배출되는 공정입니다.

SIMULATION 03 / 실측 논문자료 검증

Ca/Si 등 원소별 비율 일정 가설 검증

한 실험 조건에서 정한 원소별 용출 비율을 다른 조건에 적용했을 때 예측값이 관측값과 얼마나 다른지 확인합니다.

검증 가설: 일정한 유리 조성에서 원소 기준 비율이 다른 시험 조건에서도 유지된다고 가정합니다. 이는 검증을 위한 단순 가설이며 실제 유리의 법칙으로 인정된 명제가 아닙니다.

검증식

R기준 = NL(기준원소, 기준조건) / NL(Si, 기준조건)
NL(Si, 예측) = NL(기준원소, 대상조건) / R기준
절대오차 = |예측 − 실측|

NL은 정규화 원소 용출량(g/m²)입니다. 본 자료는 158일째 한 시점의 결과이므로 시간에 따른 용출 속도를 직접 추정하지 않습니다.

가설에 대한 판정과 원자료 점검

감마 조사 여부 외에 용액의 pH와 방사선 분해 생성물 등이 다를 수 있습니다. 원소별 변화 차이를 감마선 자체의 단일 인과효과로 확정하지 않습니다. 또한 두 실험 조건의 불확실성이 완전히 독립적이라는 가정은 검증되지 않았습니다.
SIMULATION 04 / 심화: 물질수지 검토

수용액 측정량과 표면층 잔류량의 차이

특정 원소가 수용액 밖의 표면 변질층에 남아 있을 때, 측정값만으로 전체 이탈량을 추정하면 어떤 차이가 생기는지 비교합니다.

M총이탈 = M수용액 + M변질층
α = M변질층 / M총이탈
M총이탈 = M수용액 / (1 − α)

2020년 연구 Gin 등의 ISG 시험에서 90℃, 규산 포화, pH 7 조건으로 형성된 겔층의 B 평균 잔류 비율은 약 12%로 추정되었습니다. 일반 법칙이나 다른 시험의 측정값이 아닙니다.

가정과 한계

외부 유출·별도 침전 항을 무시하고, 총이탈 원소가 수용액 또는 변질층에만 분포한다고 가정합니다. 이미 정의된 동일한 원소 질량을 다루고, 가상 상대단위를 사용합니다. 이 식은 물질수지 계산이며 특정 원소의 총이탈량은 유리 전체의 변질 질량과 동일하지 않습니다. 아래의 별도 반응–확산 모형은 문헌 측정 속도가 아닌 가정값으로 계산합니다.

검증 미완료: 실제 실험 시료의 변질층 잔류량을 독립적으로 측정한 데이터가 없으므로, 보완 추정값이 실제 총이탈량과 더 일치하는지는 검증하지 못함.

SIMULATION 04-B / 교육용 반응–확산 경쟁

반응만 고려한 플럭스와 확산 저항을 고려한 플럭스

심화개념을 정의한 후 같은 입력 조건에서 두 모형을 비교합니다. 실제 핵폐기물 유리의 측정 속도가 아닙니다.

Da = kₛ δ / Dₑff
J반응 = kₛ ΔC
J결합 = J반응 / (1 + Da)
